    ☁️ Cloudinary Setup

    Setup ke 4 qadam (ek dafa karna hai)
    1. cloudinary.com par free account banayein — dashboard par Cloud name milega, upar daalein.
    2. Settings → Upload → Add upload preset: naam adab_unsigned, Signing mode: Unsigned, Asset folder: adab-gallery. Save.
    3. Settings → Security → "Resource list" ko allowed rakhein (Restricted media types mein us par tick NA ho) — isi se gallery page sab tasveerein list kar pata hai.
    4. Cloud name website ki assets/js/data.js (cloudinary.cloudName) mein bhi daalein taake sab visitors ko gallery dikhe — ya mujhe (Claude) bata dein, main daal dunga.

    Data Backup

    Poori website ki tafseel (edits, poems, shagird posts) ek file mein save karein — hosting badalte waqt kaam aayegi.

    ⚠️ Zaroori Maloomat — Hosting ke baare mein

    Filhal ye website browser ki local storage mein data rakhti hai — matlab admin panel se ki gayi tabdeeliyan sirf isi computer aur browser mein dikhti hain, doosre logon ko nahi.

    Jab aap home server setup karein (jaisa aapne bataya), to hum is data ko ek chhoti backend/database mein shift kar denge taake:

    • Admin panel ki tabdeeliyan sab visitors ko dikhein
    • Shagirdon ki posts sab logon ko real-time dikhein
    • PDFs seedhe server par host hon (bade files ke liye behtar)

    Filhal ke liye: Data Export button se apna kaam mehfooz rakhein, aur home server tayyar hote hi mujhe bataiye — main migration kara dunga.
